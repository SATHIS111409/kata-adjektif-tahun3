Nota Kata Adjektif Tahun 3

1. Kata Adjektif Bentuk

Menerangkan rupa bentuk sesuatu benda atau objek.

Bulat Contoh: Bola, Bumi
Bujur Contoh: Telur, Cermin
Leper Contoh: Duit syiling, Pinggan
Lurus Contoh: Pembaris, Jalan
Bengkok Contoh: Cangkuk, Dawai
Kemik Contoh: Tin terhempas

2. Kata Adjektif Sifat / Keadaan

Menerangkan sifat, perwatakan atau keadaan sesuatu/seseorang.

Rajin Suka berusaha & buat kerja
Pemalu Segan berhadapan orang
Berani Tidak takut cabaran
Sihat Tubuh segar & tidak sakit
Baik Mempunyai perlakuan terpuji
Cermat Hati-hati & berwaspada

Tetapan Google Apps Script

Masukkan URL Web App daripada Google Apps Script milik cikgu supaya markah murid tersimpan terus ke dalam Google Sheet.

Kod Google Apps Script (Tampal dalam Extensions > Apps Script):

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Auto-create headers if sheet is brand new
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Tarikh/Masa", 
        "Nama Murid", 
        "Kelas", 
        "Markah Akhir", 
        "Masa Digunakan (Saat)", 
        "Jumlah Percubaan", 
        "Ringkasan Jawapan"
      ]);
      sheet.getRange(1, 1, 1, 7).setFontWeight("bold").setBackground("#d9ead3");
    }
    
    var data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      new Date(),
      data.studentName || "Tanpa Nama",
      data.studentClass || "Tiada Kelas",
      data.score || 0,
      data.completionTime || 0,
      data.attempts || 0,
      JSON.stringify(data.answers || [])
    ]);
    
    return ContentService
      .createTextOutput(JSON.stringify({ "status": "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ "status": "error", "message": err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
